# Gerador de imagens a partir de texto com ia
O projeto consiste em usar uma I.A para transformar textos digitados pelo usuário em imagens.
Usamos a lib Pil para exibir a imagem após gerarmos com nosso prompt.
OBS: Para resgatar sua KEY e usar no projeto acesse o site oficial da Openai crie sua conta e gere uma nova key de ativação e cole onde está aparecendo "sua key da Openai".

## Rodando projeto

Clone o projeto

```bash
  git clone https://github.com/python-brasil/Gerador_de_imagens_a_partir_de_texto_com_ia.git
```
Recomandamos criar uma venv antes de instalar as dependências
```bash
  python -m venv venv
```
em Linux
```bash
  python3 -m venv venv
```
Instale as dependências

```bash
  pip install -r requirements.txt
```

em Linux

```bash
  pip3 install -r requirements.txt
```
